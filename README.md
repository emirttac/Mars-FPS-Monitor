# SOURCE_CODES

Curated **core** C# sources from Mars FPS Monitor — enough to read the architecture without the full tree.

**Included:** app bootstrap, overlay/config, ETW FPS, sensors, Win32 helpers, UI code-behind, localization, update check, OC manager + vendor providers.

**Not included:** AI OC client/models/prompts, remote preset fetcher, XAML markup, assets, installer payloads.

These files are snapshots for reference. The live project root is the source of truth for builds.
